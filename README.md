# Services

Репозиторий содержит материалы, связанные с различными (мелкими) сервисами, с доступом к которым возникают проблемы в рабочей или домашней сети.  
Здесь собраны данные, которые могут использоваться при построении правил маршрутизации, фильтрации, сегментации и сетевой политики.

## Содержимое репозитория

- [Services_CIDR.txt](Services_CIDR.txt) — список IP-адресов и CIDR-диапазонов различных сервисов
- [Services_DNS](Services_DNS) — список доменных имён различных сервисов

## Назначение

Материалы репозитория могут использоваться для:

- анализа сетевого взаимодействия отдельных сервисов
- подготовки данных для маршрутизации и фильтрации трафика
- применения сетевых политик в рабочей или домашней инфраструктуре
- систематизации сервисов, требующих отдельной сетевой обработки

## Примечание

Материалы данного репозитория опубликованы исключительно в образовательных, исследовательских и административных целях.  
Они предназначены для изучения принципов сетевой обработки трафика и управления доступом к отдельным сервисам в рабочей или домашней сети.
